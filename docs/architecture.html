AI Agents

Core Logic

Planner

LLM reads user intent + dataset context → outputs JSON plan with handler IDs or codegen tasks. Sole decision-maker — no hardcoded keywords.

Step Executor

Resolves handler.id from registry → execute. On failure → silent codegen fallback. Auto-retry on sandbox errors.

Auto-Clean

Deterministic analysis + AI planning. Decides which clean handlers to run based on data issues found.

Auto-Prepare

AI analyzes target + dataset → picks optimal PrepConfig → runs 10-step pipeline → returns train/test splits.

Interpreter

LLM explains codegen results using actual computed data. Handler results use summaries directly (no LLM call).
